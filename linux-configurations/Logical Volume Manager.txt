=== LVM ===
Logical Volume Manager

LVM is used to manage volume and disk on the Linux server. Logical Volume Manager allows disks to be combined together 

Like partition of disk in windows C/D/E drive. Similarly we can do the same in the linux. 
	* Single disk can be divided into different partitions. 
	* Multiple disks combined and group them into one -> then change it into different partitions

LVM Structure Diagram

 * Raw Disk => Physical Volume => merge into => Volume Group => configured into => Logical volume/ Multiple mountpoint
 
Example: 
													 Logical Volume
Raw disk 1 200GB ---------------------------------------------------> |==> mounted on /boot (mountpoint) 
Raw disk 2 2.5TB ¯¯| => =>Physical Volume =>  1 Volume Group 3TB   => |==> mounted on /home (mountpoint) 
Raw disk 3 500GB __|							 					  |==> mounted on / 	(mountpoint) 
																	  |==> mounted on /etc  (mountpoint) 
																	  |==> mounted on /apps (mountpoint) 
																	  |==> mounted on /tmp  (mountpoint) 
					
* When multiple physical disk is merged into one volume group -- its easily managable. 
* Multiple physical disks can be merged and create one single volume group
	then the single volume group can divided into multiple partitions mounted to different mountpoint(drive)
	
Advantage of LVM
* if disk is running out of space, you can add new physical disk to the volume group without breakin partitions of the file system. 

Possibilites of LVM: 
	* New space can be created on a server for new project. 
	* In case of low disk space, inrease the space
	* In case of extra space allocated to a partition, capacity can be reallocated (reduce capacity in one group to another)

					
Various Combinations of LVM 
	* A single hard disk can be splited into two or multiple physical volume
	
		Physical disk 1 => Physical Volume 1 
						=> Physical Volume 2 
	
	* Multiple physical volume can be merged into one volume group 
	
	* Multiple logical volume of a single volume group
	
		Volume Group 1 => Logical volume 1
					   => logical volume 2
	
	* two different hard disk/physical disk can be set up as two physical volume and two/multiple different physical volume can be merged into a single volume group
	* Multiple physical volumes can be merged in a single volume group 
	* In one server there can be multiple volume groups.

#Storage Extention

1. Create partition to extend: 
	syntax: fdisk /dev/disk_name
	command: fdisk /dev/sdb
	
	process: same as partition creation. 
	for checking: p
	
2. Create physical volume from the partition: 
	syntax: pvcreate /dev/disk_name
	command: pvcreate /dev/sdb2
	for checking: 
		pvscan
		pvdisplay
		pvs

3. Extending the volume group: 
	syntax: vgextend volume_group_name_to_be_exteneded from_which_physical_disk_it_will_be_extended
	command: vgextend vg-sdb1 /dev/sdb2
	
4. Extending LVM: 
	syntax: lvextend -L +[size] lvm_path
	command: lvextend -L +488MB /dev/vg-sdb1/lv-vg-sdb1
		* for size you need allocate the size shown on vgdisplay PE size
	for checking: 
		lvscan
		lvdisplay
		
5. Expanding the file system
   For finding: check df -hT mounpoint type
	for xfs
	syntax: xfs_growfs /mounpoint_folder
	command: xfs_growfs /apps_logs/
	
	for ext4
	syntax: resize2fs lvm_path
	command: resize2fs /dev/vg-sdb1/lv-vg-sdb1
	
6. systemctl daemon-reload (if needed)

Storage Removal

1. remove fstab entry from /etc/fstab
	#UUID=1c57c1ce-631f-43d6-bc00-a8541255038f /apps_logs xfs       defaults        0 0

2. unmount the mountpoint 
	syntax: umount /mountpoint_name
	command: umount /apps_logs
	
3. remove LVM: 
	syntax: lvremove /dev/volume_group_name/lv_name
	command: lvremove /dev/vg-sdb1/lv-vg-sdb1
	
4. Remove Volume group
	syntax: vgremove [volume_group_name]
	command: vgremove vg-sdb1
	
5. Remove Physical Volume
	syntax: pvremove /dev/physical_volume_name
	command: pvremove /dev/sdb1 
			 pvremove /dev/sda2

6. to check: lsblk

7. Remove the partition: 
	syntax: fdisk /dev/partition_name
	command: fdisk /dev/sdb
	
	for deleting partition: d 
	select partition number: 1/2/3 (do it muliple if partition is more than one)
	
	save & exit: w

To check free space of a disk. 
	syntax: parted /dev/disk_name
	command: parted /dev/sdb

	command: print free

 *** ৫ নাম্বার ফিল্ডটি ব্যবহার করার হয় Dump প্রোগামের জন্য। যদি ভ্যালু '1' সেট করা হয়, তাহলে Dump ইউটিলিটি পার্টিশন ব্যাকাপের জন্য কাজ করবে।  
আর যদি ভ্যালু '0' সেট করা হয়, তাহলে Dump ইউটিলিটি পার্টিশন ব্যাকাপের জন্য কোনও কাজ করবে না। 

Backup operation – the fifth field contains a 1 if the dump utility should back up a partition or a 0 if it shouldn’t. If you never use the dump backup program, you can ignore this option.

 6 - file system check options

 *** ৬ নাম্বার ফিল্ডটি ব্যবহার করার হয় 'fsck' (Fiel System Checking) প্রোগামের জন্য। সিস্টেম বুটিং এর সময় ডিভাইস/ পার্টিশনের Errors চেক করে।  এখানে '0' উল্লেখ করলে 'fsck' কাজ করবে না। আর যদি রুট পার্টিশনের ক্ষেত্রে '1' এবং অন্য পার্টিশনের ক্ষেত্রে '2' সেট করা হয়, তাহলে সিস্টেম বুটিং এর সময় ফাইল সিস্টেম চেক করবে। 

File system check order – the sixth field specifies the order in which fsck checks the device/partition for errors at boot time. A 0 means that fsck should not check a file system. Higher numbers represent the check order. The root partition should have a value of 1 , and all others that need to be checked should have a value of 2.
